# أطلس ALBAZ لرؤية الهلال بمعيار SAO

صفحة ويب عربية مستقلة لعرض وحساب مناطق إمكانية رؤية الهلال وفق معيار **SAO / SAAO جنوب أفريقيا**.

## الإصدار

`v9.6.3 Web Edition`

## التشغيل

افتح ملف `index.html` في متصفح حديث، أو انشر محتويات هذا المجلد مباشرة عبر GitHub Pages.

## النشر عبر GitHub Pages

1. أنشئ مستودعًا عامًا جديدًا، والاسم المقترح: `ALBAZ-SAO-Hilal-Atlas`.
2. ارفع الملفات مع إبقاء `index.html` في جذر المستودع.
3. افتح **Settings → Pages**.
4. اختر **Deploy from a branch** ثم الفرع `main` والمجلد `/ (root)`.
5. احفظ الإعدادات؛ سيظهر رابط الصفحة بعد اكتمال النشر.

## ملاحظات تقنية

- الصفحة لا تحتاج إلى خادم خلفي أو قاعدة بيانات.
- لا توجد طلبات شبكة أو مكتبات CDN خارجية.
- الخريطة والبيانات الأساسية مضمّنة داخل `index.html`.
- أزيل تضمين خط Janna LT Bold من نسخة النشر العامة لأن بيانات الترخيص الموجودة داخل الخط تمنع إعادة توزيعه. تستخدم الصفحة خطوط النظام العربية المتاحة محليًا.

## التحقق

تم اختبار النسخة في Chromium: تحميل الواجهة، تعبئة قائمة 196 عاصمة، حساب نقطة بغداد، حساب خريطة سريعة، فتح نافذة حول البرنامج، وعدم ظهور أخطاء JavaScript.
