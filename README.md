# ALBAZ Odeh + SAAO Crescent Visibility Atlas

## أطلس الباز لرؤية الهلال — معيارا عودة وSAAO

صفحة ويب عربية مستقلة لحساب وعرض مناطق إمكانية رؤية الهلال وفق معيارين علميين:

- معيار **محمد عودة (Odeh)**.
- معيار **مرصد جنوب أفريقيا الفلكي (SAAO)**.

## الإصدار

`v9.6.3 Web Edition`

## التشغيل

افتح `index.html` في متصفح حديث. تعمل الصفحة دون خادم خلفي، ولا تحتاج إلى قاعدة بيانات أو مكتبات CDN خارجية.

## GitHub Pages

الملف `index.html` موجود في جذر المستودع وجاهز للنشر من الفرع `main` والمجلد `/ (root)`.

## الخصائص

- اختيار معيار عودة أو SAAO.
- حساب خرائط إمكانية رؤية الهلال.
- حساب نقطة جغرافية محددة.
- دعم العربية والإنجليزية والاتجاه RTL/LTR.
- تشغيل الحسابات الثقيلة بواسطة Web Worker.
- تصدير التقارير والصور من المتصفح.
- تشغيل محلي دون اتصالات خارجية.

## ملاحظة الخط

أزيل تضمين خط Janna LT Bold من نسخة GitHub العامة امتثالًا لشروط ترخيص الخط. تستخدم نسخة الويب خطوط النظام العربية المتاحة محليًا.

## الحقوق

إعداد وتطوير: **الفيزيائي عمر الباز**  
رئيس مبرمجين أقدم — عضو الاتحاد العربي لعلوم الفلك والفضاء.

جميع الحقوق محفوظة. لا يمنح وجود الشفرة في هذا المستودع ترخيصًا بإعادة الاستخدام أو إعادة التوزيع ما لم يصدر إذن صريح من صاحب المشروع.
